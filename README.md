# Heart Disease Prediction Using Machine Learning

## Project Overview
This project uses machine learning to classify heart disease status
from clinical features in the UCI Heart Disease dataset.

## Models
- Logistic Regression
- Random Forest
- Decision Tree

## Results

| Model | Accuracy | F1-Score | ROC-AUC |
|---|---:|---:|---:|
| Logistic Regression | 88.5% | 88.1% | 96.6% |
| Random Forest | 86.9% | 86.2% | 94.5% |
| Decision Tree | 73.8% | 72.4% | 74.5% |

## Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

## Dataset
UCI Heart Disease Dataset:
https://archive.ics.uci.edu/dataset/45/heart+disease

## How to Run
1. Open the notebook in Google Colab.
2. Run the cells from top to bottom.
3. Review the model evaluation results.
